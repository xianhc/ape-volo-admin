# 岗位模块

以仓库中已有的岗位管理为例，串起实体、服务契约、动态接口、前端请求、列表和表单。岗位对应代码名称为 `Position`，表名为 `sys_position`。

- [后端文件与接口](backend-module-example.md)
- [前端文件与交互](frontend-page-example.md)

## 按改动顺序查阅

1. 核对实体、契约与 DTO，确认字段、查询条件和对外方法。
2. 核对服务实现、映射、权限码，以及是否涉及事务或缓存。
3. 按 [接口契约](../contract.md) 核对生成的请求路径、动词和响应类型。
4. 更新前端请求类型、列表和表单，保持菜单权限与按钮权限一致；岗位选项还被用户管理页面使用。
5. 按改动执行 [后端检查](../backend.md#检查) 和 [前端检查](../frontend.md#检查)，验证分页、增删改、导出、状态切换和用户岗位选择中受影响的操作。

新增业务模块时可沿用这一顺序，按实际能力选择所需文件；岗位的用户关联和启用状态等约束应按业务需要设计。
